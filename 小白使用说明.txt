PlayAtlas 世界游戏馆：小白使用说明

一、当前版本能做什么

这是一个离线优先的独立项目源码与预览包。打开大厅后可以搜索、筛选
36 个目录条目；其中六款样板有互动预览：五子棋、扫雷、克朗代克接龙、
贪吃蛇、Oware、卡罗姆。预览会明确写“互动样板”，不等于已经完成
Windows/安卓人工验收。

二、最快打开方式（Windows）

1. 安装 Python 3.11 或更高版本。
2. 双击 START_PREVIEW.bat。
3. 浏览器打开后，在卡片上点击“查看详情”，再点击“开始游戏”。
4. 关闭浏览器或命令窗口不会联网，也不会上传资料。

三、命令行检查

在项目目录打开命令提示符：

  run_qa.bat

看到报告路径后，打开 reports\qa\qa_report.md。只有报告里写明“已自动测试”
的项目才算通过了当前无图形规则检查；“待验证”不能当作已完成。

四、打开 Godot 工程

使用 Godot 4.7.2 或兼容的稳定版打开本目录，入口场景是：

  ui\CoreShell.tscn

本次工作区没有 Godot 可执行文件，所以没有替你伪造 Windows 启动结果。

五、常见问题

- 浏览器显示空白：不要双击 index.html，先双击 START_PREVIEW.bat，让页面
  通过本地地址加载。
- 端口被占用：在命令行运行
  python tools\run_headless_smoke.py --serve --port 8766
  然后打开 http://127.0.0.1:8766/preview/ 。
- 找不到 Godot：安装 Godot 4.7.2 后重新打开项目；不要把当前源码 ZIP
  说成已经导出的 Windows 程序。

六、状态含义

“可玩/样板”只描述当前代码或预览表面；正式发布还需要真实流程、教程、
存档、视觉、音频、触屏和目标设备验收。请以 GAME_STATUS.md 和
reports\qa\qa_report.md 为准。
